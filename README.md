# Calculadora de notas

Proyecto de ejemplo para practicar Git y GitHub mediante trabajo colaborativo.

## Estructura

- `index.html`: interfaz principal.
- `script.js`: validación y cálculo del promedio.
- `style.css`: estilos y validaciones visuales.
- `README.md`: documentación del proyecto.

## Uso local

1. Clona el repositorio.
2. Abre `index.html` en un navegador.
3. Escribe tres notas entre 0 y 5.
4. Pulsa **Calcular promedio**.

## Flujo de ramas

```bash
git checkout -b interfaz
git checkout -b logica
git checkout -b estilos
```

Cada integrante debe trabajar en su rama, hacer commits descriptivos y crear un Pull Request para revisión antes de fusionar los cambios en `main`.
